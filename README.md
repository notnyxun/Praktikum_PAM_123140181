## 🚀 Cara Menjalankan Proyek (Kotlin / Android)

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/notnyxun/Praktikum_PAM_123140181.git
   ```
2. **Buka folder tugas yang diinginkan di Android Studio** (misal: folder `2_123140181`).
3. **Lakukan Gradle Sync** di Android Studio.
4. **Jalankan aplikasi** pada Emulator atau Perangkat Android Fisik melalui menu **Run** (`Shift + F10`) atau via terminal Gradle:
   ```powershell
   .\gradlew.bat :androidApp:installDebug
   ```
